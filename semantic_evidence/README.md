## Critical interpretation limits

- The native control projections replace callbacks. Their success paths do
  **not** show credentials passing the original gate.
- Isolated comparator tests use a SHA dependency and artificial target strings.
  They verify argument bytes, comparison length, prefix/suffix and branches,
  not a preimage of the real username hash.
- The full original decoder *loop* runs for the 12 nonempty string slots;
  global cache, C++ lifetime and Windows initialization are outside that test.
- Live-field accessor tests execute original getter instructions. Opcode 58
  conversion tests execute four original bodies with immediate/stack adapters.
  These checks do not lift every surrounding VM instruction or guard.
- The tail fixture uses a fixed artificial key and a 65-byte artificial
  intermediate, not the real ciphertext. One existing cipher pass is run for
  each slack setting without `FAST_DES`; resulting outputs are checked by the
  isolated original shape predicate. No original valid username is known.
- Original string metadata is not demonstrated to be forgeable through input.
  The two inconsistent-metadata cases only establish what the predicate reads.
- 24 native callback kinds, 16 observed logical VM instruction kinds and 409
  observed bytecode instruction boundaries are different coverage measures.
  Unobserved VM instruction kinds are not declared unreachable.

## Reproduce

Install Python dependencies `pefile`, `capstone`, `unicorn`. From the repository:

```sh
python scripts/pafet_semantic_map.py --out semantic_evidence_new/static
python scripts/pafet_semantic_probe.py
```

For native observations, build in `scripts/native` as described in its README,
then run from the repository root:

```sh
python scripts/pafet_semantic_probe.py --native scripts/native/native_probe --opcode-projection --tail-validation
```

The optional source inventory needs a checkout of
[NIKJOO/VSEC-REVoid at the assessed commit](https://github.com/NIKJOO/VSEC-REVoid/tree/a7ceb544a2cec1cd534154a52d9e382b51c7fa81).
Pass `--revoid /path/to/checkout`; this is unnecessary for Pafet component tests.
The recorded inventory hashes the three source files and identifies the commit.
The generator engine itself is not present in that checkout.

The raw main trace can be regenerated within `scripts/native`:

```sh
SEMANTIC_OPS=1 ./native_probe --script-control 0 1 1
```

Main control variations change three booleans, a fixed clock seed and unused
host return values. User control variations use six modeled lengths and five
character-result values. Those are bounded semantic experiments, not credential
candidates. Repeating tests can choose different dispatch clones and runtime
seeds, so raw addresses/opaque state need not match byte-for-byte. Assertions
check semantic invariants, not those changing values.
